# Outbound: block

Молча отбрасывает весь трафик, направленный на данный outbound. Используется как «чёрная дыра» для сброса нежелательных соединений.

## Схема

| Поле | Тип | По умолчанию | Описание |
|------|-----|--------------|----------|
| `type` | `"block"` | — | Должно быть `"block"`. |
| `tag` | string | — | Уникальная метка для этого outbound. |

## Пример

```json
{
  "type": "block",
  "tag": "block"
}
```

## Примечания

- Все соединения, маршрутизированные на этот outbound, немедленно закрываются без обмена данными.
- Поля dial, TLS и transport не применимы.
- Удобен для блокировки рекламы, вредоносных доменов или любой категории трафика через правила маршрутизации.
