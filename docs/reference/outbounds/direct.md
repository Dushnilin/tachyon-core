# Аутбаунд `direct`

Прямое соединение без проксирования. Принимает маршрут по умолчанию и всё, что не перехватили правила.

## Обязательные поля

| Поле | Тип | Описание |
|---|---|---|
| `type` | string | Значение `direct`. |
| `tag` | string | Имя объекта. По нему ссылаются `route.rules`, `dns.rules`, `detour` и группы. |

## Собственные поля

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `override_address` | string | -- | Адрес, отправляемый вместо настоящего. |
| `override_port` | uint16 | -- | Порт, отправляемый вместо настоящего. |
| `proxy_protocol` | boolean | -- | Предварять соединение заголовком PROXY. |

## Общие поля

Поля диалера — [dialer](../common/dialer.md).


## Ограничения

Поля `server` и `server_port` не принимаются: аутбаунд `direct` не обращается к серверу. `detour` **запрещён** — валидатор отклоняет конфиг с сообщением ``detour`` is not supported in direct context, потому что заворачивать прямое соединение в цепочку бессмысленно: маршрут и так выбирается правилами.
