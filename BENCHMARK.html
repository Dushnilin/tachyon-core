🦀 Rust 2024 / tachyon-core НУЛЕВЫЕ АЛЛОКАЦИИ
Нулевые аллокации в relay-цикле, прямое использование ядра Linux (splice, recvmmsg, zero-copy buffers), чистый Rust криптостек без сборщика мусора (GC) и без C FFI. Итог: 4.2 MiB RAM (меньше даже C-ядра!), старт 22.3 ms и пропускная способность 51.7 Gbps.
⚙️ C / Steer (OpenWrt) МАРШРУТИЗАЦИЯ
Выдающийся размер бинарников (1.76 MiB суммарно) и минимальная базовая память (5.1 MiB). Однако разделение на 3 процесса с IPC через сокеты и отсутствие пакетного батчинга ограничивают throughput потолка до 8.0–9.6 Gbps с повышенным CPU оверхедом 1.07 s/G.
🐹 Go 1.26 / sing-box, Xray, Mihomo ТЯЖЕЛЫЙ RUNTIME
Высокая производительность на одном долгом сокете (48–53 Gbps), но плата за Go неизбежна: базовое потребление 25–40 MiB RAM, паузы сборщика мусора при частых сессиях, холодный запуск от 160 до 270 ms и бинарники весом до 76 MiB.

🛠️ Методология тестирования и конфигурация стенда
Тестирование проводилось в изолированном Docker-контейнере Linux (WSL2 kernel 6.18.33.1, AMD Ryzen 7 5800X3D). Для исключения взаимного влияния потоков применяется жесткая изоляция CPU affinity (taskset): клиент нагрузки генерирует трафик строго на Core 0, тестируемый прокси-процесс исполняется строго на Core 1 (в однопоточном режиме: TACHYON_WORKERS=1, GOMAXPROCS=1), а целевой апстрим-сервер занимает ядра Cores 2-5. Замеры памяти производятся через /proc/[pid]/smaps_rollup с фиксацией PSS/RSS (для Steer суммируется всё дерево процессов: connector, steerd, steer-dnsd, модули steer-proxy, steer-vless, steer-extended, steer-hysteria2). Замер холодного старта фиксирует время от момента exec() до первого успешного TCP/SOCKS handshake.
