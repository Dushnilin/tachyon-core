# Аутбаунд `selector`

Группа с ручным выбором участника. Переключается через Clash API или LuCI.

## Поля

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `type` | string | -- | Имя типа объекта. |
| `tag` | string | -- | Имя объекта. По нему ссылаются `route.rules`, `dns.rules`, `detour` и группы. |
| `outbounds` | string / array | -- | Теги участников группы. |
| `default` | string | -- | Участник по умолчанию. |
| `interrupt_exist_connections` | boolean | -- | Разрывать активные соединения при переключении. |

Участник выбирается вручную: через Clash API (`PUT /proxies/<tag>`)
либо панелью LuCI. `default` — участник до первой ручной установки; если он
не указан, берётся первый из списка `outbounds`.

Ссылаться на группу можно в `route.rules` (`outbound`) и в `detour`.
