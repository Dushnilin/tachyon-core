# Инбаунд: Direct

Транзитный инбаунд, который принимает сырые TCP/UDP-соединения и передаёт их напрямую в маршрутизатор (с возможностью подмены целевого адреса и порта).

## Схема конфигурации

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `type` | string | Да | Должно быть `"direct"`. |
| `tag` | string | Нет | Уникальный идентификатор инбаунда. |
| `listen` | string | Да | Адрес прослушивания. |
| `listen_port` | uint16 | Да | Порт прослушивания. |
| `network` | string | Нет | `"tcp"`, `"udp"`, либо не указано (оба протокола). |
| `override_address` | string | Нет | Переопределение целевого IP или домена. |
| `override_port` | uint16 | Нет | Переопределение целевого порта. |

## Пример (локальный перехват DNS)

```json
{
  "type": "direct",
  "tag": "dns-in",
  "listen": "127.0.0.1",
  "listen_port": 5353,
  "network": "udp",
  "override_address": "1.1.1.1",
  "override_port": 53
}
```
