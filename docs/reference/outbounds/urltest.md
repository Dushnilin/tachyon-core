# Аутбаунд `urltest`

Группа с автоматическим выбором участника по задержке.

## Поля

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `type` | string | -- | Имя типа объекта. |
| `tag` | string | -- | Имя объекта. По нему ссылаются `route.rules`, `dns.rules`, `detour` и группы. |
| `outbounds` | string / array | -- | Теги участников группы. |
| `url` | string | -- | URL проверки задержки. |
| `interval` | string | -- | Интервал проверки, вида `3m`. |
| `tolerance` | uint32 | -- | Допуск задержки в мс. |
| `idle_timeout` | string | -- | Не проверять, если нет активных соединений. |
| `interrupt_exist_connections` | boolean | -- | Разрывать активные соединения при переключении. |
| `mode` | string | -- | Стратегия выбора: `lowest`, `round_robin`, `least_load`. |
| `balancer` | object | -- | Стратегия балансировки для режимов с несколькими участниками. |

Каждые `interval` ядро проверяет задержку до каждого участника и
переключает выбор на лучший. `tolerance` удерживает текущий участника, пока
конкурент не станет быстрее более чем на это число миллисекунд — это убирает
метания между близкими по пингу нодами.

`idle_timeout` откладывает проверки, пока через группу нет трафика.

Проверка идёт HEAD-запросом через сам аутбаунд участника, задержка считается
**после установления соединения**, поэтому совпадает с цифрой в панели.
