# Аутбаунд `snell`

Аутбаунд Snell.

## Обязательные поля

| Поле | Тип | Описание |
|---|---|---|
| `type` | string | Значение `snell`. |
| `tag` | string | Имя объекта. По нему ссылаются `route.rules`, `dns.rules`, `detour` и группы. |
| `server` | string | Домен или IP-адрес сервера. |
| `server_port` | uint16 | Порт сервера. |

## Собственные поля

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `version` | uint16 | -- | Версия Snell: `1`, `2`, `3`, `4`, `5`. |
| `psk` | string | -- | Предварительно согласованный ключ. |
| `userkey` | string | -- | Ключ пользователя для версий 2–3. |
| `reuse` | boolean | -- | Переиспользовать соединение. |
| `network` | string | -- | Какие сети задействовать. |

## Общие поля

Поля диалера — [dialer](../common/dialer.md), блок `tls` — [tls-client](../common/tls-client.md).


## Ограничения

Аутбаунд Snell реализован как клиент TCP-туннеля. Фазы 1–3 (`userkey`, reuse мультиплекса) не поддерживаются.
