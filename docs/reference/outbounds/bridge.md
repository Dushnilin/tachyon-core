# Аутбаунд `bridge`

> **Принимается проверкой конфига, но не реализован в рантайме.** `run` завершится ошибкой `outbound type "bridge" not implemented yet`.
Мост между интерфейсами.

## Поля

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `type` | string | -- | Имя типа объекта. |
| `tag` | string | -- | Имя объекта. По нему ссылаются `route.rules`, `dns.rules`, `detour` и группы. |
| `interface` | string | -- | Имя интерфейса. |
| `bridge_name` | string | -- | Имя моста для создания. |
| `iproute2_table_index` | uint32 | -- | Индекс таблицы маршрутизации iproute2. |
| `iproute2_rule_index` | uint32 | -- | Индекс правила маршрутизации iproute2. |

Мост между интерфейсами создаётся средствами ядра Linux.
