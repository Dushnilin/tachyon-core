# Аутбаунд `chain`

Цепочка аутбаундов: соединение проходит по ним подряд.

## Поля

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `type` | string | -- | Имя типа объекта. |
| `tag` | string | -- | Имя объекта. По нему ссылаются `route.rules`, `dns.rules`, `detour` и группы. |
| `outbounds` | string / array | -- | Теги аутбаундов цепочки, выполняются по порядку. |
| `idle_timeout` | string | -- | Таймаут простоя звена. |
| `strip_evasion` | boolean | -- | Убирать маскировочные заголовки на стыках цепочки. |
| `strip` | boolean | -- | Убирать маскировочные заголовки. |
| `rewrite` | boolean | -- | Переписывать адреса между звеньями. |
| `interrupt_exist_connections` | boolean | -- | Разрывать активные соединения при перестройке цепочки. |

`outbounds` — список тегов, соединение проходит по ним по порядку:
сначала первый, затем второй как транспорт для первого и так далее.

Используется для схем вида «реальный сервер, прикрытый VPS-переходником».
