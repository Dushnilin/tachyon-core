# Инбаунд: Redirect

Прозрачный перехват TCP-соединений через Linux netfilter `REDIRECT` (восстанавливает оригинальный адрес назначения через `SO_ORIGINAL_DST` / `IP6T_SO_ORIGINAL_DST`). Работает только для TCP — для прозрачного перехвата UDP используйте `tproxy`.

## Схема конфигурации

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `type` | string | Да | Должно быть `"redirect"`. |
| `tag` | string | Нет | Уникальный идентификатор инбаунда. |
| `listen` | string | Да | Адрес прослушивания. |
| `listen_port` | uint16 | Да | Порт прослушивания. |

## Пример

```json
{
  "type": "redirect",
  "tag": "redir-in",
  "listen": "::",
  "listen_port": 7892
}
```
