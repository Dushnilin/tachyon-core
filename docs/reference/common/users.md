# Пользователи

Поле `users` — массив объектов с учётными данными клиентов.

## HTTP и SOCKS (инбаунды `mixed`, `http`, `socks`)

```json
"users": [
  { "username": "user", "password": "pass" }
]
```

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `username` | string | — | Имя пользователя. |
| `password` | string | — | Пароль. |

У `mixed` аутентификация работает и для HTTP Basic 407, и для SOCKS5.

## VLESS, VMess, Trojan, AnyTLS (серверные инбаунды)

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `uuid` | string | — | Идентификатор пользователя. |
| `password` | string | — | Пароль. Только для `trojan` и `anytls`. |
| `name` | string | — | Имя для учёта и логов. |

## Shadowsocks (серверный инбаунд)

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `password` | string | — | Пароль или PSK. |
| `method` | string | — | Шифр, если он отличается от общего. |
| `name` | string | — | Имя для учёта. |

Пустой список пользователей у протоколов с авторизацией — ошибка конфигурации:
сервер без клиентов работать не должен.
